# 과제: 도서 대출 API
{TOOL_LINE}
이 폴더(비어 있음)에 Spring Boot 4 REST API 서버를 만든다. 화면, 로그인, 권한은 만들지 않는다.

- Java 17 이상, Gradle(Gradle wrapper 포함), 데이터베이스는 H2 메모리.
- 이 PC에서 8080 포트는 다른 프로그램이 쓰고 있다. 서버를 띄워 확인할 때는 포트 {PORT}를 쓴다.
- 이 PC에서는 다른 사람의 프로그램(java 등)도 돌고 있다. 프로세스를 이름으로 종료하지 않는다. 직접 띄운 서버는
  그 서버를 띄운 방법으로(예: 백그라운드 작업을 기록해 두고) 끈다.

## 기능

1. 도서: ISBN(숫자 13자리, 필수, 중복이면 409), 제목(1~200자, 필수), 저자(1~100자, 필수), 출판 연도(1450~2100),
   보유 권수(0 이상, 필수). 등록, 한 건 조회, 수정, 삭제. 목록은 페이지 단위로 보고 제목 오름차순이며, 제목 일부나
   저자 일부로 검색할 수 있다.
2. 회원: 이름(1~50자, 필수), 이메일(형식 검사, 필수, 중복이면 409), 가입일(서버가 정함). 등록, 한 건 조회, 수정,
   목록.
3. 대출: 회원과 도서를 지정해 대출한다. 대출일과 반납 예정일(대출일 + 14일)은 서버가 정하고, 반납일은 반납 전에는
   비어 있다.
   - 없는 회원이나 없는 도서로는 대출할 수 없다(404).
   - 도서의 남은 권수(보유 권수 - 반납되지 않은 대출 수)가 0이면 대출할 수 없다(409).
   - 반납: 대출 한 건을 반납 처리하면 반납일이 기록된다. 이미 반납된 대출을 다시 반납하면 409.
   - 회원별 대출 목록(반납하지 않은 것만 골라 볼 수 있어야 한다)과 도서별 대출 목록.
4. 잘못된 입력은 400, 없는 데이터는 404로 답한다.

## 끝내기 전에

- `./gradlew build`가 성공해야 한다.
- 서버를 포트 {PORT}로 띄워 도서·회원 등록 → 대출 → 남은 권수 0일 때 409 → 반납 → 다시 반납 409까지 직접
  확인한다. 확인한 뒤 서버는 끈다.
- README.md에 실행 방법과 API 목록(메서드, 경로, 예시 curl)을 쓴다.
